## 💖 Nosso Tempo Juntos 💖

<p>Um aplicativo web feito com amor em React/JavaScript, apresentando um contador em tempo real do nosso relacionamento, uma galeria de fotos e uma mensagem especial.</p>

### 🚀 Sobre o Projeto 🚀

<p>Este projeto é um presente de aniversário de namoro criado para celebrar os 8 anos do nosso relacionamento (desde 17 de Outubro de 2017).
</p>

<p>O objetivo é criar uma experiência pessoal e emocionante que inclui:</p>

<p>Contador de Tempo em Tempo Real: Exibição precisa de anos, meses, dias, horas, minutos e segundos desde o início do namoro.</p>

<p>Galeria de Fotos: Uma coleção de momentos especiais em formato de carrossel ou grade.</p>

<p>Mensagem de Amor: Um texto dedicado e pessoal.</p>

### ✨ Tecnologias Utilizadas ✨

<h4>O projeto foi construído utilizando as seguintes tecnologias:</h4>

<ul>
     <li><p>Frontend Framework: React;</p></li>
     <li><p>Linguagem: JavaScript (ES6+);<p></li>
     <li>Estilização: CSS;</li>
</ul>
